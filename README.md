## 📌 Featured Projects

### [MyPL](https://github.com/JamesHagan-prog/MyPL)
MyPL is a fictitious Programing Language developed by myself as a full interpreter.
Code goes through the interpreter through a lexer, parser, and then into an AST. The AST is then interpreted in a JVM.
This project is a fully functioning DEBIAN package, so it can be installed on any machine and be used like any other language.

**Tech:** Java, Maven, DEBIAN

---

### Merge Request Health Bot
The Merge Request Health Bot (MRHB) is a pipeline to help developers work more efficiently. 
Developed as a GitLab extension, the MRHB automatically receives merge requests, lint's them, and then uses a rag pipeline to generate smart fixes. 
This project uses AI in a way to aid developers, not replace them.

**Tech:** Python, Flask, AWS
